....# ☁️ CloudStore | Modern Storage Interface

A premium, clean, and highly sophisticated UI for cloud-based file management systems.

## ✨ Features
- **Sophisticated Design**: Clean white/blue "Azure" inspired aesthetic with high-quality shadows.
- **Folder Grid**: Organized representation of file categories with status indicators.
- **Interactive Sidebar**: Intuitive navigation for "Recent", "Starred", and storage analytics.
- **Search Optimization**: Focused UI for quick data retrieval and organization.

## 🛠️ Tech Stack
- **Languages**: HTML5, CSS3 (Modern Flexbox/Grid).
- **Fonts**: Inter for accessibility and premium feel.

## 🧠 Why I built this?
To showcase my ability to design industrial-grade software interfaces. Distributed storage is a key CSE topic, and this UI demonstrates the user-facing side of cloud engineering.
